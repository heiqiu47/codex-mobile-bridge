PR #86 引入第三方 Codex 重置统计与预测。用户要求先实际体验，再决定是否需要，不能将本轮试用视为正式接纳或发布。

## 决策

在 `trial/pr86-reset-outlook` 合并原始 PR 提交，保留 heiqiu47 的作者记录；本地 `main` 保持 `6a4c666`，不推送远程。Mac Test 使用现有独立身份与运行目录。

卡片默认关闭，开关对当前网关的全部设备生效。固定请求 `codex-reset.com` 公共接口，不携带账号凭据；共享缓存限制正常刷新间隔为 30 分钟，手动刷新冷却 60 秒，429 遵循退避。关闭卡片后不发起新的查询或提醒，已开始的只读请求可能完成并保留缓存。

界面说明第三方预测不代表个人额度，通知将重置声明归于第三方来源。卡片提醒默认关闭，沿用账号提醒的第三方通道，不新增手机通知或自动启用真实通知。开启提醒以当前时间为基线，不补发旧事件。原有账号额度查询与展示仍独立运行。
