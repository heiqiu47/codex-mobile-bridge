# Agent Note: 重置动态的本地体验与接纳边界

Status: implemented

## 问题

PR #86 引入第三方 Codex 重置统计与预测。用户先要求独立体验，完成 Mac Test 实测后批准纳入本地 main；接纳不等于允许远程推送或发布。

## 决策

原始 PR 提交先在 `trial/pr86-reset-outlook` 完成体验，试用期间 main 保持 `6a4c666`。用户实测接受后，将完整提交历史纳入本地 main，保留 heiqiu47 的作者记录，不推送远程。Mac Test 沿用现有独立身份与运行目录；本次接纳后的文字与样式修改只提交源码，不隐含已重新编译安装。

设置入口名称为“Codex官方重置动态”，卡片默认关闭，开关对当前网关的全部设备生效。固定请求 `codex-reset.com` 公共接口，不携带账号凭据；共享缓存限制正常刷新间隔为 30 分钟，手动刷新冷却 60 秒，429 遵循退避。关闭卡片后不发起新的查询或提醒，已开始的只读请求可能完成并保留缓存。

界面说明第三方预测不代表个人额度，通知将重置声明归于第三方来源。卡片提醒默认关闭，沿用账号提醒的第三方通道，不新增手机通知或自动启用真实通知。开启提醒以当前时间为基线，不补发旧事件。原有账号额度查询与展示仍独立运行。铃铛旁显示“提醒已开启／提醒已关闭”，表示配置状态，不保证未配置通道时能够送达。提醒列表仅清除复选框继承的输入框边距与内边距，使其与文字垂直居中。

## 验证

原 PR 的 24 项预测与提醒测试、111 项账号后端测试、72 项定向前端测试通过。完整前端回归 1283 项通过、1 项既有跳过。新增真实 DOM 浏览器用例检查默认提醒关闭、深浅主题、窄屏无横向溢出、失败隐藏预测以及关闭卡片；既有 API 表单检查一起运行。构建、安装与实际数据获取证据保存在 `.tmp/pr86-20261028/`，这些产物不提交。

接纳阶段新增默认关闭检查，41 项账号测试、24 项预测提醒测试、72 项前端定向测试通过；8 项浏览器验证覆盖状态切换、深浅主题和宽窄屏。对齐缺陷先在 WebKit 窄屏复现中心偏差 2.5 px，修复后单行与换行均通过中心偏差不超过 1 px 的断言。

## 备选方案

在实测前直接纳入 main 能减少分支切换，但用户当时需要先判断功能价值，因此先保留独立体验分支；用户完成体验后的明确接纳授权结束了该阶段。只展示截图无需替换 Test，却不能验证真实刷新和数据质量，不满足上手体验要求。

## 影响

本地 main 包含已接受功能，但已安装 Test 仍是实测版本，新增文案与对齐需下次编译后进入安装包。第三方可用性、统计口径与预测准确度不是 Bridge 能保证的事实；不得据此更改账号额度或主动消费重置卡。本轮只验证 Mac Test，不宣称其他操作系统已经实机验收。
