# Agent Note: DSH 原生 Mobile 与独立插件兼容契约

Status: implemented

## 问题

Issue #91 的用户实测表明，第三方 DSH 的 Mobile 链接可以直接用于手机 WebView，但现有 `GatewayURL` 只接受 Bridge 网关地址，会拒绝 Tauri 的 `?auth=` 等参数。用户要求同时保留原客户端 Mobile 界面和 Bridge 统一聊天界面，并将接入插件视为可独立安装的 Harness 插件，而非按应用名称识别的专用适配。

旧通用插件绑定要求安装文件与当前网关内置源码逐字节相等，插件补丁不能独立升级。此次用户批准只在本地实现、回归并编译 Test，不推送、不发布。

## 决策

手机保留严格的 `GatewayURL`，另设 `DshMobileURL`、加密保存的独立连接列表与独立浏览容器。手动入口明确选择 DSH Mobile；扫码遇到非 Bridge 链接时进入 DSH 确认，普通根地址也可显式选择 DSH。校验允许 HTTPS 和局域网 HTTP，保留认证路径、查询参数与片段，拒绝 URL 用户信息、控制字符、反斜杠和非法端口。列表和确认只展示来源，不泄露认证参数。

Android 的 DSH Activity 不导出，使用独立进程与 WebView 数据目录；iOS 使用独立临时 `WKWebsiteDataStore`。二者均不注入 Bridge 脚本、注册 Bridge 原生消息处理器或调用网关探测、通知与账号 API。外链经用户操作确认后交给系统浏览器，回退使用网页历史。Bridge 原有通知来源、主题和会话菜单保持原路径；原生 DSH 网页的主题与通知由该客户端决定。

插件保持标准 `dsh.bundle.patch`，导出自包含 ZIP 和 npm 格式 `.tgz`，不携带连接凭据、不设安装脚本。版本 `0.2.x` 声明独立的线协议 1、消息修订 9；核心范围暂时精确为已验证的 `0.2.1-rc.2`，不以客户端品牌替代核心版本证据。协议兼容补丁不再校验文件字节一致，但安装清单、私有绑定身份与认证状态握手必须一致；每次操作前核对运行版本，防止更新磁盘包后仍由旧进程接受写入。未知协议或版本系列明确拒绝。

绑定前只读预览实际档案、数据目录和插件版本，确认绑定时重查实例 ID。绑定继续限制为同机私有文件及认证回环端点，保留原 token 指纹、实例、目录关系和未知写入不重放约束。手动接入不退出或启动第三方客户端，不改其账号与会话。旧 `0.1.0` 包保留已知源文件哈希检查。官方修订 9 与本次附加握手字段具有相同官方协议，其旧 LF/CRLF 源文件继续作为兼容版本复用，避免迫使现有正式版接入更新。

### 手机连接列表与顶栏

DSH Mobile 与 Bridge 网关在“我的电脑”中按最近打开时间统一排序。两端仅在原生偏好中记录 `last-opened:dsh:<opaque-id>` 时间，不把完整 Mobile 链接加入网关地址、探测或后台通知集合。扫码确认和打开已保存连接都更新时间；已有条目没有时间记录时使用原有确定性排序，首次重开后进入最近顺序。移除连接同时移除该时间记录。

DSH 卡片使用横排等宽的连接与移除按钮，移除沿用网关的危险色；顶栏两侧使用可访问性标注的电脑与刷新图标，标题居中。iOS 保留网页侧滑返回，Android 保留系统返回的网页历史处理。该改动不改变原生 DSH 网页本身的主题、内容或通知。

### 市场发布准备

当前官方市场没有默认索引；标准格式 1 支持 npm 或固定提交的 Git 安装源。本轮先完善包的作者、仓库与操作说明，在忽略目录生成索引草稿，并用已验证核心的官方解析器检查安装目标。草稿时间戳 0 仅是本地验证占位，真正发布时必须读取已发布包的真实时间。尚未发布 npm、公开索引或推送远程，不把准备完成表述为市场已上架。源码中的 `plugin/` 缺少导出时合入的 host 与许可证，必须发布导出的完整包。

## 备选方案

- 放宽全局 `GatewayURL` 能以更少代码接受链接，但会把外部网页混入 Bridge 的 Cookie、原生接口及后台探测路径。因此使用两类明确的连接。
- 在同一 WebView 存储中仅省略脚本，可以减少原生容器代码，但同域不同端口的 Cookie 仍可能共享。采用独立存储，并接受旧系统与临时会话的限制。
- 继续按源文件精确匹配可强制网关和插件完全同步，但不适合独立发行插件。新系列用显式版本及协议握手；旧系列仍保留已知哈希。
- 立刻将核心范围扩为所有后续版本可以让安装更方便，但开发预览核心存在破坏性接口变化，现有证据不足。因此只声明实际测试核心，待新版本回归后再放宽。

## 验证

两端原生 URL 测试覆盖完整参数保留、来源显示脱敏、私网 IPv6、公网 HTTP 拒绝、凭据与端口边界，并确认 Bridge 地址规则未放宽。Python 插件测试覆盖兼容补丁、未知协议拒绝、磁盘与运行版本不一致时写入不发送、只读预览及确认时实例变化。Node 测试运行真实封装与回环 host，验证插件身份声明和既有会话操作。官方接入回归覆盖新旧修订 9 的 LF/CRLF 源码复用且不写入安装文件。

Android APK、iOS 模拟器与 Mac Test 网关构建及 Mac 签名校验通过；前端完整回归 1,283 项通过，完整后端运行 2,792 项，其中 31 项按平台跳过、其余通过，DSH 后端 100 项通过，模块边界和 86 篇笔记校验通过。

使用缓存的 Tauri v0.25.0 插件与 Harness 0.2.1-rc.2，在本轮独立档案中通过真实 `dsh plugin` 离线安装 `.tgz`，原生插件管理器自动加入 bundle。Mac 合成运行时使用 `sandbox-exec` 限制网络为回环地址，本地假模型验证聊天、历史、手机收件箱、Webhook、归档和同 ID 恢复，无外部模型费用。新 Mobile 端点使用 Tauri 自带 `remote` 插件，启用仅回环的测试端口和合成 `?auth=` 链接。Android 模拟器实际进入原始聊天 UI，并检查返回电脑列表与地址脱敏；iOS XCTest 验证添加、原页面加载、关闭及从保存连接重新打开。初次 iOS 测试因未签名 App 缺少钥匙串权限失败，改用模拟器 ad-hoc 签名后同一流程通过；未用明文回退规避失败。

Windows 使用本机 DSH Desktop 2.0.18 附带的 Harness 0.2.1-rc.2，以及现有 Tauri 的同版核心与插件；Linux 使用任务目录中独立安装的官方 0.2.1-rc.2 核心，不改全局工具或真实 DSH 档案。两系统的合成核心使用 Node socket guard 限制出站为回环地址（不是操作系统网络沙箱），均通过真实 CLI 安装导出包、配对、聊天、历史、手机收件箱、Webhook、归档与恢复。Windows Desktop 核心和 Linux 官方核心还验证两张原生问答卡片同时待回复、回复一张后另一张保留，以及请求通知；该证据不扩大为所有工具审批类型的端到端验证。Windows Tauri 原生 Mobile 页面通过；两系统官方网页入口按启动令牌换取 Cookie、跳转干净 URL、再次打开的完整流程通过，匿名请求仍返回 401。初次 HTTP 探针未保存重定向签发的 Cookie 而失败，补验浏览器语义后通过，未放宽产品认证。

Windows、Linux 各自的 DSH 后端 100 项通过，前端回归与冻结程序烟测通过；Windows 冻结包另验 WSL 路径及终端入口。Linux 共同回归初次因 umask 002 使合成身份目录可被组写入，触发生产代码的正确拒绝；测试夹具现在显式使用目录 0700、身份文件 0600，并增加组可写目录必须拒绝的用例，不修改生产检查。修正后 Linux 共同回归 169 项通过，原失败日志保留。安装后的两台冻结网关还在隔离配置中实际导出 ZIP 与 `.tgz`，核对七个独立文件、版本 0.2.0 和两个包的内容一致。Windows 更新后的 Codex WSL 时间线与 Claude WSL 历史抽查通过，只发 GET，不激活或重连原会话；Claude 样本首次返回 400，后续同一路径读取成功，未据此宣称已定位或修复新的产品缺陷。

手机列表补充回归 `python3 scripts/test-mobile-computer-order.py` 编译并执行两端实际排序表达式，覆盖两种连接混排、旧条目重开和网关集合不混入 DSH。手机源码回归 62 项、原生 URL 边界及 Android/iOS 模拟器构建通过；Android 覆盖安装成功。此次桌面工具未能连接 Android 与 iOS 模拟器界面，未将编译或安装作为视觉验收证据。市场草稿通过官方解析器，精确安装目标为 `dsh-codex-mobile-bridge@0.2.0`。

证据在忽略目录 `.tmp/dsh-dual-route-20261029/` 与 `.tmp/dsh-mobile-ui-20261029/`。本轮 iPhone 在系统设备列表中不可用，没有声明 iPhone 真机安装或实测；其他第三方客户端及其他核心版本没有新增实测结论。

## 影响

手机可直接使用第三方 DSH Mobile 原界面，也可继续通过通用插件使用 Bridge 统一聊天。两条路线不混用认证及原生能力。Android 8 的 DSH 入口需经确认在浏览器打开，原 Bridge 功能不变；iOS 关闭外部页面后不保留 Cookie，重新进入依赖保存的 Mobile 链接，一次性链接需要重新生成。移除书签不等于撤销客户端签发的认证。

市场安装所需标准包已具备，但此次未发布 npm 或公开市场索引。官方 Harness 不默认内置索引源，不能把本地导出称为已经上架。插件来源仍由用户信任，协议握手不等同于签名验证。当前网关仍只有一个活动 DSH 档案；不借本次改动扩展多实例 provider 模型。
