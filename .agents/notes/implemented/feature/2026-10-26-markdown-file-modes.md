# Agent Note: Markdown 文件的阅读与源码模式

Status: implemented

## 问题

Markdown 文件只能阅读渲染结果，无法直接查看完整原文；引用位置仍需要源码行定位。

## 决策

Markdown 采用 HTML 已有的模式按钮外观，阅读使用现有渲染器，源码使用 BridgeSourceView。复制按钮始终复制服务端原文。用户主动切换记为浏览器全局默认，新打开文件采用此默认；引用位置强制源码且不覆盖默认。每个标签分别保存两种模式的纵横滚动位置，模式变化同步工作台的滚动缓存。源码 DOM 在模式间保留，并显式恢复内部滚动容器的纵横位置，保留自动换行选择。工作台标签切换也恢复源码内部滚动容器，避免节点卸载重置横向位置。

每次阅读实例拥有独立 Mermaid scope。退出阅读、关闭标签或重置工作区均清理 scope，阻止过期异步渲染和残留全屏图表。工作台自身全屏保持同一内容节点，沿用原有标签滚动恢复。

## 既有笔记审计

源码视图笔记部分重叠，继续约束精确原文、独立行号和高亮；本决定只负责 Markdown 模式与生命周期，不替换源码组件。

## 备选方案

- 把源码作为独立标签：可同时查看，但消耗文件标签数量，且偏离已有 HTML 模式交互。
- 所有 Markdown 继续共用工作台 Mermaid scope：缓存复用较多，但单个模式清理会影响其他已打开文件。

## 影响

切回阅读会重新创建图表 scope；原文不经渲染内容重建。默认设置本地保存失败时仍可切换，但重载后回到阅读。HTML、PDF 和图片预览保持现有路径。
