# Agent Note: 统一 Claude 聊天列表

Status: implemented

## 问题

分开的 Code、Cowork、CLI 分组打断按时间浏览。用户也需要在不丢失时间顺序的前提下快速筛选混合列表。

## 决策

默认在同一最近列表显示全部 Claude 聊天类型。完整可读清单至少有两种类型时，显示仅含实际出现类型的 All/Code/Cowork/CLI 选择器，并在每个标题旁、原日期上方放紧凑类型标签。选择器在时间顺序列表内过滤；搜索、归档可见性、项目分组、活动指示和选择行为仍可用。单一类型清单隐藏选择器。创建对话框独立管理聊天类型选择。

共享会话列表通过同一秒转毫秒转换来排序和展示日期。Desktop 活动时间戳可能为毫秒，本地和 SSH CLI 历史使用 Unix 秒；直接比较原始数字会让 CLI 会话排在更旧的 Desktop 会话后。转换属于列表展示层，保留现有后端时间戳及使用方契约。

## 备选方案

可折叠类型分组使按时间浏览活动更困难。可选选择器能筛选混合列表而不按类型分组。项目分组仍是显式展示选择，可跨类型按项目分组。

## 影响

选定类型按 provider 保存；该类型从完整清单消失时重置为 All。搜索及归档可见性不决定选择器是否显示。现有项目折叠偏好仍作用于项目分组。DOM 测试覆盖按时间混合、自适应类型过滤、归档/搜索、项目分组和 provider 切换；响应式外观在集成时验证。

混合时间单位 DOM 回归检查全局顺序、可见 CLI 日期，以及类型、搜索、项目过滤后的顺序。不声称已运行真实 Claude Desktop 或 SSH 集成。
